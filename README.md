# Hollowmere: The Night the Veil Thins

A scroll-driven WebGL landing page for a fictional Halloween festival. The whole page is one continuous camera flight through a haunted world built from painted cut-outs placed at real 3D depth.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
npm run build            # static site in dist/ (works from any folder or host)
npm run build:artifact   # also writes dist/artifact.html for publishing on claude.ai
npm run textures         # re-run after replacing any PNG in assets/
```

`dist/` is a plain static site: drag it onto [Netlify Drop](https://app.netlify.com/drop) or upload it to any static host.

Dev-only shortcuts: `/?skip` bypasses the séance loader, and `/?skip&p=0.55` lands at a scroll position (0–1).

## The journey

| Chapter | What happens |
|---|---|
| Séance loader | The planchette spells E-N-T-E-R as assets load. Touching it burns the board away (noise-threshold dissolve). |
| The Gates | 10+ depth layers. The cursor is a pendulum-physics lantern that lights the world and reveals hidden spirits. |
| The Threshold | Scroll swings the gates open, a bat swarm bursts past, and the camera flies down a lantern-lit path. |
| The Veil | The camera flies into the manor's rose window through a spiral portal (post-processing warp). |
| Deck of Fates | Six tarot cards on a rotating ring with a holographic foil shader. Each card flips as it arrives. |
| The Oracle | A crystal ball with live fbm smoke inside. Click it for a fortune. |
| Witching Hour | Real clock hands scrub from *now* to midnight. The bell tolls and the world turns blood-red. |
| Apothecary | Potions are the ticket tiers. Pouring one splashes and recolours the cauldron brew. |
| Invitation | The wax seal shatters into shards (vertex-shader explosion) and the RSVP letter opens. |
| Graveyard | Tombstones are the footer links. Skeleton hands burst out on hover. |

Five hidden spirits can only be found with the lantern. Finding all five unlocks a discount code in the RSVP letter.

## Structure

```
assets/            original PNGs (never modified)
public/tex/        optimised WebP textures (generated by scripts/optimize.py)
src/main.js        renderer, scroll, camera, interaction, main loop
src/timeline.js    Hermite camera spline, environment keys, zones
src/shaders.js     shared uniforms + GLSL materials (lit cut-outs, fog, ghosts, flames, sigils…)
src/world/*.js     one module per chapter
src/fx/post.js     bloom + custom veil pass (lantern mask, portal warp, CA, grain)
src/audio/         fully procedural Web Audio sound design (see below)
src/loader.js      séance loader
src/cursor.js      lantern cursor physics
src/ui.js          HTML panels, rail, countdown, RSVP
scripts/           texture optimiser + artifact page converter
```

## Sound design

Every sound is synthesised at runtime (`src/audio/`), with no audio files:

- **Score** (`score.js`): a generative D-minor progression. A detuned music-box lullaby plays in the valley, a formant choir in the veil, a pipe organ in the clock tower, and bowed low strings build tension on the path (they swell with scroll speed).
- **Ambience** (`ambience.js`): wind, crickets, owls, wolves, creaking branches, veil drone and whispers. The clock, cauldron and oracle are **3D positional**, so they pan and fade as the camera flies past.
- **Scroll stingers** (`index.js`): gate creak and clang, bat swarm, a portal "braaam", harp glissando, twelve bells at midnight and more, plus a continuous air rush tied to scroll velocity and a flame whoosh as each pumpkin passes.
- **Interaction**: the lantern plays a theremin as it moves (pitch follows height, quantised to the scale), and there are hover sounds, quill scratches while typing, and a heartbeat near hidden spirits.
- **Mix** (`engine.js`): buses feed a hall reverb (outdoors) and a cathedral reverb (inside the veil), then a compressor and limiter. The mix ducks under big stingers and is muffled while the RSVP letter is open. The sound on/off setting is remembered.

## Notes

- The RSVP form has no backend. Submissions are validated and stored in `localStorage` only.
- All sound is synthesised at runtime, so there are no audio files.

## Performance

- **No first-visit hitches**: every shader compiles (asynchronously) and every texture uploads to the GPU while the séance loader plays.
- **Adaptive quality**: the frame rate is sampled continuously. Below ~48 fps the renderer steps down resolution and MSAA (5 levels), and it steps back up after sustained headroom.
- **Only what's near is drawn**: each chapter's scene is hidden when the camera is elsewhere.
- **Allocation-free render loop**: hover raycasts only run when the pointer or camera moves.
- **Textures**: 78 MB of source PNGs become 8 MB of WebP, and the séance images are preloaded so the loader paints immediately.
